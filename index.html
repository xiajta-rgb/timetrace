02 · 指标体系

D — S — T：
先把"人到底发生了什么"拆清楚。

拒绝伪心理学的"幸福指数"。我们只做事实层、结构层、留痕层的可计算拆分， 再让 AI 进行事实性解释。

D1
时间投入

我的时间去了哪里？

流向 9 大类生活场景：工作 / 学习 / 家庭 / 社交 / 独处 / 睡眠 / 通勤 / 杂务 / 其他。只记录，不评价。

D2
时间重复

多少日子是相似的？

相似日占比、重复活动、重复路径、重复社交、重复内容消费。回答「为什么一年过去却感觉什么都没发生」。

D3
时间事件

出现了多少区分度事件？

新地点 · 新人物 · 新体验 · 新行动 · 意外 · 认知变化。注意："事件" ≠ "任务"。一次任务完成可能没有形成任何独特经历。

S1
未来导向

我的意识有多少在围绕未来？

识别：计划 / 目标 / 预期 / 担忧 / 规划 / 为未来准备。未来导向 ≠ 不好，真正要观察的是它是否长期挤占当下。

S2
结果导向

我是否只在结果里找意义？

做完了吗？达成了吗？有产出吗？对应：我在过程中发现了什么？体验到了什么？结果导向本身是一条轴，不做两个独立因子。

S3
主体参与

是我在生活，还是事情带着我走？

主动选择 / 探索 / 创造 / 表达 / 改变 ↔ 被动执行 / 接受。回答："这段时间是我在生活，还是事情在带着我走？"

T1
体验痕迹

是否形成可回忆的具体节点？

"那天晚上下很大的雨。" "第一次去了那家店。" 重点不在数量，在于有没有形成具体、独特的记忆节点。

T2
认知变化

我有没有变得不一样？

新发现 / 新理解 / 旧观点被推翻 / 新兴趣 / 新价值排序 / 对自己的重新认识。经历不一定带来快乐，但真正的经历往往会留下变化。

T3
关系连接

人与人之间是否留下了痕迹？

新认识 / 深度交流 / 关系变化 / 共同经历 / 情感表达 / 被理解。≠ 社交时间，独处两小时也可能经历很深。

01
不做"越高越好"

重复度高、未来导向高，也可以是稳定的好生活。指标只描述结构，不替你下判断。

02
评价放在关系结构

真正有价值的不是单项分数，而是不同维度组合后呈现的"时间结构"。

03
高中低三档，不做加分项

1–3 低 / 4–7 中 / 8–10 高。高 ≠ 好，低 ≠ 坏，让数据保持中性。

时痕是时间管理工具吗？

不是。时痕不帮你安排时间，也不提醒你做事。它只做一件事：让你看见自己正在怎么经历时间。安排时间是你的事，安排完之后的"自己过得怎么样"，才是时痕的事。

为什么不做"幸福指数"？

因为"幸福"是一个价值判断，会让 AI 替用户评价人生。时痕只做事实层、结构层、留痕层的可计算拆分，再做事实性解释。是否"过得好"，留给你自己。

数据隐私如何处理？

所有日记默认加密本地存储。云端同步采用端到端加密，AI 解读在沙箱环境内进行，不参与任何模型训练。你可以随时一键导出或彻底删除。

我需要每天写很多吗？

不需要。系统设计支持"碎片化记录"：一段话、一句话、甚至一个关键词都可以。AI 会帮你补全结构。但坚持 30 天以上，画画像的稳定性才会显现。

免费版够用吗？

如果你只是想体验"看见自己"这件事，免费版已经够。如果你想跨周期对比、生成年度报告、做长期趋势，Pro 是为这件事准备的。
