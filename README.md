# 时痕 TimeTrace

> 让成年人第一次看见自己正在怎么活，而不是只在使用时间。

时痕 TimeTrace 是一套**为成年人设计的时间体验记录工具**。基于 D-S-T 时间体验指标体系（9 维 × 56 因子），用 AI 自动从日记中抽取结构化信号，构建个人画像，识别"时间被压缩"还是"时间在创造"。

## ✨ 核心能力

- **📊 D-S-T 指标体系**：发生 / 结构 / 留痕 三层，9 个一级维度，56 个二级因子
- **🤖 AI 自动抽取**：写日记自动识别关键词，按因子归类
- **📈 5 个观察指标**：时间压缩度 / 体验密度 / 结果化程度 / 生命参与度 / 时间留痕度
- **🎯 画像自动识别**：任务化 / 探索型 / 稳定陪伴 三种典型模式
- **📐 周 × 日热力图**：时间模式 + 周期性检测
- **🔗 跨维度相关性**：哪些维度总是一起高/低
- **📦 完整数据架构**：五层解耦 · 事件总线 · 仓储可替换
- **💾 本地优先**：所有数据存储在 localStorage · 可加密导出

## 🏗 架构（解耦五层）

```
UI (Views)
   ↓ 订阅 Store.subscribe
State (EventBus + Store)  ← 单一数据源
   ↑ emit
Service (业务编排)
   ↓ call
Repository (数据访问抽象)
   ↑ inject
Domain (实体 + 纯函数)
```

详见 [`docs/factors.html`](docs/factors.html) 因子指标体系白皮书。

## 🚀 快速开始

每个 HTML 文件都可以独立运行：

```bash

open index.html

# 方式 2：本地服务器
python -m http.server 8765
# 然后访问 http://localhost:8765/
```

## 📐 因子指标

56 个因子从 6 个维度系统梳理，每个因子包含：

1. 定义（测什么）
2. 情绪切点（为什么关心）
3. 典型表达（用户怎么写出它）
4. 关键词云（AI 抽取的关键词）
5. 反面信号（缺乏时会出现什么心理状态）
6. 引导话术（数据少时如何引导补充）

详见 [`docs/factors.html`](docs/factors.html)。

## 🧪 开发理念

- **零依赖**：单文件 HTML，无任何外部库
- **离线可用**：所有逻辑在浏览器中运行
- **数据本地**：默认存储在 localStorage，不上云
- **可测试**：Domain 层是纯函数，可在 Node 直接单测
- **可扩展**：五层架构 + Repository 抽象，可一行替换为 IndexedDB / LLM
